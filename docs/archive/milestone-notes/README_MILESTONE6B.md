# Milestone 6B — Cross-Dimension RTL Validation

Milestone 6B validates whether the calibrated model generalizes beyond cache-capacity changes by changing AXI backing-memory latency and cache capacity together.

Frozen points are generated by `scripts/run_milestone6a.py` **before** RTL execution:

- I$64 / D$64 / LAT=1
- I$64 / D$64 / LAT=5
- I$256 / D$64 / LAT=2
- I$256 / D$256 / LAT=5

After running the VCS bundle and extracting its results at the project root:

```bash
python scripts/compare_milestone6b.py
```
