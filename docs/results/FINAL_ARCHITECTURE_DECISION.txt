  Cycle speedup vs BASE        : 2.218x

Decision
--------
- Minimum physical area: BASE_64_64
- Minimum benchmark cycles: PERF_512_64
- Best equal-clock performance per physical core area: EFF_256_64
- Balanced physical architecture recommendation: EFF_256_64
- Performance-first recommendation when area is secondary: PERF_512_64

Timing limitation
-----------------
No SRAM-aware Fmax or wall-clock performance claim is made. The physically
matched RAM2P_128x16 Liberty contains placeholder 999-ns clock-to-Q values.
